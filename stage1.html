Демонстрация

Сырой GPS «дрожит» вокруг реальной траектории. Скользящее среднее — простая замена фильтра Калмана (EKF): чем шире окно, тем глаже линия, но тем больше запаздывание на поворотах. Нормализация изображений: x' = (x − min) / (max − min).

import cv2, numpy as np
img = cv2.imread('frame.jpg')
img = cv2.GaussianBlur(img, (5,5), 0)          # фильтрация шума
img = cv2.normalize(img.astype('float32'), None, 0, 1, cv2.NORM_MINMAX)
