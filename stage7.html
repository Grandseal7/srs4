Этап 7. Принятие решений

Система сама решает, когда снимать: считает NDVI по каждому кадру и сравнивает с порогом (рисунки 2 и 3).

Выполняемые задачи

  • Расчёт NDVI = (NIR − Red) / (NIR + Red)
  • Классификация фитостресса
  • Порог NDVI → решение: съёмка или continue
  • Адаптивное управление БПЛА

Инструменты

  • Мультиспектральная камера
  • CNN–LSTM–EKF, Random Forest, Fuzzy

Демонстрация

Дрон пролетает над полем шестью кадрами. Если в кадре достаточно пикселей с NDVI ниже порога, срабатывает ветка «Да» из схемы: съёмка и сохранение координат. Иначе — continue. Здоровая растительность даёт NDVI 0.6–0.8, стресс — ниже. Данные поля синтетические, подставьте свои снимки.

ndvi = (nir - red) / (nir + red + 1e-9)
stress = ndvi < 0.35
if stress.mean() > 0.08: capture_image(get_gps_coords())
else: continue
